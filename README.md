# Epididymal Large RNA-Seq Pipeline

This repository contains the bioinformatic pipeline used for quality control, adapter trimming, genome alignment, and transcript quantification of the **Large RNA fraction (>200 nt)** from mouse epididymal tissue subjected to early-life inorganic arsenic (iAs) exposure.

---

## 📌 Repository Structure

```text
├── environment.yml          # Conda environment definition
├── scripts/                 # Execution scripts for processing steps
│   ├── 01_qc_raw.sh         # FastQC on raw reads
│   ├── 02_trimming.sh       # Read trimming via fastp
│   ├── 03_star_align.sh     # Alignment to GRCm38 using STAR
│   └── 04_quantify.sh       # Gene quantification via featureCounts
└── results/                 # Output directories (generated upon run)
```

---

## 🛠️ Installation & Environment Setup

All dependencies are managed via Conda/Mamba.

```bash
# Clone the repository
git clone [https://github.com/YourUsername/epididymis-large-rna.git](https://github.com/YourUsername/epididymis-large-rna.git)
cd epididymis-large-rna

# Create environment from YML file
conda env create -f environment.yml
conda activate large_rna_env
```

---

## 🚀 Workflow Execution Steps

### 1. Raw Read Quality Control
Run `FastQC` to evaluate read quality prior to trimming:
```bash
bash scripts/01_qc_raw.sh
```

### 2. Adapter Trimming & Quality Filtering
Adapter sequences and low-quality bases are removed using `fastp` (paired-end mode enabled):
```bash
bash scripts/02_trimming.sh
```

### 3. STAR Genome Indexing & Alignment
Trimmed paired-end reads are aligned to the mouse reference genome (**GRCm38.p4**, GENCODE vM10 annotation) using `STAR` (v2.7.11b):
```bash
bash scripts/03_star_align.sh
```

### 4. Gene Quantification
Gene-level quantification is performed using `featureCounts` (RSubread package), strictly accounting for library strandedness (reversely stranded, `-s 2`) and paired-end mode (`-p`):
```bash
bash scripts/04_quantify.sh
```

### 5. MultiQC Report Generation
Aggregate processing reports across all samples:
```bash
multiqc results/ -o results/09_multiqc/
```

---

## 📊 Downstream Differential Analysis

Quantified read count matrices generated by `featureCounts` serve as the input for downstream differential expression analysis (`DESeq2`) and Gene Set Enrichment Analysis (`GSEA`) in R.
